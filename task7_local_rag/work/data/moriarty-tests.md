# Тестовые сценарии Moriarty

Moriarty используется для создания контролируемых случаев, позволяющих проверять отдельные этапы работы 221B.

## Test Case A — Red Lantern
Сценарий содержит последовательность событий, в которой после трёх стабильных измерений возникает паттерн `RED`. Ожидается, что Holmes обнаружит `RED`.

## Test Case B — Blue Window
Сценарий содержит события, соответствующие условиям паттерна `BLUE`, но не содержит идентификатора источника. Ожидается, что Holmes обнаружит `BLUE`, а Lestrade переведёт случай в `REVIEW`.

## Test Case C — Gold Finch
Сценарий содержит четыре последовательных события, необходимых для обнаружения `GOLD`. Ожидается, что Holmes обнаружит `GOLD`. При этом стандартный процесс Beta 0.8 не должен автоматически передавать такой случай на проверку Lestrade.

## Test Case D — Broken Report
Holmes обнаруживает паттерн `RED`, но возвращает пустой `CaseReport`. Сценарий используется для проверки поведения Watson при отсутствии данных для объяснения.
