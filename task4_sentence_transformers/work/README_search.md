# Семантический поиск по документации Python

Основная работа: `work/semantic_search_research.ipynb`.

## Запуск

Из папки проекта:

```sh
docker compose up --build -d
```

Откройте `http://127.0.0.1:8888/?token=sentence_transformers`, затем папку `work` и новый ноутбук. Выполните ячейки сверху вниз. Демонстрационный ноутбук сохранён без изменений.

Все импорты находятся в первой кодовой ячейке, настройки — в следующем разделе. Первый запуск требует интернета для загрузки документации и моделей. Корпус, версии моделей и эмбеддинги сохраняются в папке `work`. Повторное выполнение использует кэш; проверка его отпечатка защищает от использования эмбеддингов другого текста.

Dockerfile настроен на CPU PyTorch и фиксированные основные версии библиотек. Исходный вариант Dockerfile доступен в истории Git.

## Данные и результаты

- `work/search_data/corpus.json` — 258 документов с текстом, абзацами и URL первоисточников.
- `work/search_data/raw_html/` — исходные страницы документации Python 3.13.
- `work/search_data/queries.json` — 34 запроса, заранее разделённые на 10 dev и 24 test.
- `work/search_data/qrels.csv` — релевантные документы, обоснования и фрагменты источников.
- `work/search_data/annotation_review.html` — таблица для личной проверки разметки.
- `work/search_data/model_revisions.json` — закреплённые версии трёх моделей.
- `work/search_cache/` — веса моделей и эмбеддинги.
- `work/search_results/` — метрики, результаты по запросам, время и параметры среды.

Первоначальная разметка составлена и сверена с документацией ассистентом. Независимая ручная проверка человеком не выполнена. Чтобы выполнить именно эту часть задания, просмотрите `annotation_review.html`, проверьте полноту релевантных документов, исправьте `qrels.csv` при необходимости и отметьте `human_verified=True`. После изменения разметки повторно выполните ноутбук. Сама отметка не влияет на метрики и не выдаётся за проверку автоматически.

Размеченные документы должны непосредственно описывать нужную операцию. Пары, отсутствующие в разметке, считаются нерелевантными в пределах этой коллекции. Это учебный набор, а не готовый промышленный тест.

## Остановка

После сохранения работы:

```sh
docker compose down
```

Папка `work` остаётся на компьютере, данные и результаты не удаляются.
