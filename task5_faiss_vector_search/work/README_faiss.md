# Исследование векторного поиска с FAISS

Основной ноутбук: `faiss_research.ipynb`.

Для просмотра без Docker сохранена HTML-копия `faiss_research.html` с кодом,
таблицами, графиками и выводами.

Проверено: все 56 кодовых ячеек выполнены без ошибок; 99 ячеек всего,
максимум 22 строки кода в одной ячейке, импорты только в первой кодовой ячейке.
Сохранены 5 графиков и 16 выводов по фактическим результатам.

## Запуск

Из папки `task5_faiss_vector_search`:

```sh
docker compose up --build -d
```

Откройте `http://127.0.0.1:8888/?token=faiss_vector_search`, затем `work/faiss_research.ipynb`.
Выполняйте ячейки сверху вниз. Все импорты находятся в первой кодовой ячейке;
настройки — в последующих. Демонстрационный ноутбук и его данные сохранены.

Первичная сборка контейнера требует интернета. Само исследование использует
сохранённые данные и эмбеддинги предыдущего задания и работает без интернета.
Основные версии закреплены: FAISS CPU 1.12.0, NumPy 1.26.4.

## Данные и методика

- `input/` — точные копии корпуса, чанков, запросов, разметки и BGE-эмбеддингов из задания 4.
- `input/manifest.json` — исходные пути и SHA-256 каждого входного файла.
- Корпус: 258 документов, 430 чанков, 34 запроса (10 dev и 24 test).
- Выбрана комбинация BGE + фиксированные окна, ранее выбранная по dev.
- Во всех основных экспериментах `k=10` чанков. Сравниваются NumPy, FAISS FlatIP,
  HNSWFlat и IVFFlat. Параметры ANN выбираются на dev.
- Настоящие подколлекции имеют 100, 250 и 430 векторов. Отдельный синтетический
  нагрузочный эксперимент имеет 2 000, 10 000 и 50 000 векторов. Это не новые документы.
- Скорость поиска измеряется без повторного кодирования текстов, в один поток CPU.
- `human_verified` перенесён из исходной разметки; отсутствие отметки не подменяется
  утверждением о независимой проверке человеком.

## Сохранённые результаты

`faiss_results/` содержит таблицы метрик, исходные замеры времени, результаты
по запросам, выдачу индексов, выбранные настройки, параметры среды и графики.
В `faiss_results/indexes/` сохранены только выбранные индексы реального корпуса.
Большие синтетические коллекции и индексы не сохраняются: они восстанавливаются
по зафиксированным параметрам. При повторном выполнении время измеряется заново.

## Остановка

После сохранения ноутбука:

```sh
docker compose down
```

Все файлы в `work/` остаются на компьютере.
